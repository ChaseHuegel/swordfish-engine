# Improvement: Make the settings scrollbar draggable

- Type: improvement
- Status: open
- Workflow: ../specs/issues.md

## Problem

The settings pane scrollbar shows the scroll position but does not accept
input. The mouse wheel is the only way to scroll a long category.

## Acceptance criteria

- [ ] Dragging the scrollbar thumb scrolls the pane.
- [ ] Clicking the scrollbar track jumps toward the clicked position.
- [ ] The wheel still scrolls the pane.
- [ ] The thumb stays inside the track at both ends.
